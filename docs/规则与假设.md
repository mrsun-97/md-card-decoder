# 规则与模型假设

本文说明求解器使用的判定规则、它们的依据，以及仍未确认的假设。代码实现见
`crates/decoder-core/src/rules.rs`，测试范例见 `tests/golden/rules.toml`。

## 六项字段

| 字段 | 相符条件 | 相符时揭示 |
|---|---|---|
| 卡片边框 | 两张卡的边框有任一部分相同（灵摆卡算两种边框） | 目标卡的完整边框（如「融合／灵摆」） |
| 属性 | 相同 | — |
| 等级／阶级／连接 | 数字相同；“规则上的等级”与“卡图的等级”都算 | 目标卡的**规则**等级 |
| 种族 | 相同 | — |
| 攻击力 | 相同 | — |
| 守备力 | 相同 | — |

六项全部相符即解出本题。多张卡六项完全相同时，猜其中任意一张都算正确，所以求解器把这样的卡合并为一个“判定组”，按张数加权。

## 已确认的规则

| # | 规则 | 依据 |
|---|---|---|
| R1 | 目标是灵摆卡时，猜测卡符合其中一种边框即相符，并揭示完整边框 | 官方「卡片边框」范例 1：目标霸王龙扎克（融合／灵摆），猜幻之召唤神 艾克佐迪亚（融合）→ 揭示「融合／灵摆」 |
| R2 | 同上，经由灵摆部分相符 | 官方范例 2：猜清透翼疾速龙（同步／灵摆）→ 揭示「融合／灵摆」 |
| R3 | **猜测卡**是灵摆、目标不是灵摆时，同样按共同部分判定，揭示目标的边框 | 官方范例 3：目标艾克佐迪亚（融合），猜霸王龙扎克 → 揭示「融合」 |
| R4 | 边框相符揭示目标卡的完整边框 | 官方范例 1–3 |
| R5 | 等级、阶级、连接按同一个数字比较（4 星＝4 阶＝LINK-4） | 玩家确认（2026-09-26） |
| R6–R8 | 规则等级与卡图等级不同的卡（7 张：未来皇霍普系列、究极玛雅・卓尔金等）：双方的规则等级和卡图等级都参与比较，揭示目标卡的规则等级 | 官方「等级」范例 1–3：目标卓尔金，猜未来皇霍普 → 因卡图等级（0）相符，揭示「12」；卓尔金与绝望神 安提霍普互猜 → 因规则等级 12 相符，揭示「12」 |
| R14 | 每题开始时免费揭示一项（「记录」中的第一列灯泡） | 玩家确认 |
| R15 | 游戏内列表会按已知条件自动筛选，但可以重置筛选并选择不符合已知条件的卡 | 玩家确认 |
| R16 | 提示揭示的字段不计入相符奖励；只有提交的卡片与目标相符时才计入（即使该字段之前被提示揭示过） | 玩家确认 |
| — | 同一题中重复判定同一张卡不消耗挑战次数，也不留下记录 | 官方说明 |
| — | 次数发放：首日 4 次挑战、3 次提示；之后每天 13:00 发放 4 次挑战、1 次提示；未用完的次数累积到活动结束 | 官方说明 |

这些规则与旧版工具的实现完全一致：新旧两套判定在全部 8,210 × 8,210 = 6,740 万对卡上逐一对照，没有任何差异（`npm run data:check`）。

## 未确认的假设

| # | 假设 | 默认 | 影响范围 |
|---|---|---|---|
| R9 | 两张**不同的**卡攻击力（或守备力）都是 “?” 时算相符 | 相符 | 71 组 “?” 攻击、43 组 “?” 守备 |
| R10 | 两张不同的连接怪兽，守备力（连接怪兽没有守备力）算相符 | 相符 | 388 组连接怪兽 |
| R13 | 提示从尚未知道的字段中**均匀随机**选一个；对规则等级不同的卡，提示揭示规则等级 | 如此 | 提示的价值计算 |
| — | 目标卡按大师决斗卡池中的张数加权随机抽取 | 如此 | 先验概率 |

R9、R10 可以在“活动设置 → 规则与卡池”中切换。无论哪种设置，同一张卡（同一判定组）与自己总是相符。

**如何自己确认**：遇到猜测卡和目标卡的攻击力都是 “?”（或者两张都是连接怪兽）的挑战时，看游戏里那一行是否变黄即可。

## 录入矛盾

如果录入的线索互相矛盾（没有任何卡能满足全部记录），通常是某一条录错了。工具会逐条尝试“去掉这一条”，按恢复的候选数量排序，列出最可能录错的记录，可以一键删除该条。工具不会自动修改记录。

## 卡池

- **大师决斗卡池**（默认）：YgoMaster 提取的游戏内卡表与卡片密码映射，交叉百鸽卡库字段；9,059 张怪兽、8,023 个判定组。
- **完整官方怪兽**：9,312 张、8,210 组，仅用于候选归零时排查。
- 官方未公开活动的实际出题名单，活动可能另外排除少量卡；这会带来很小的概率误差。
